# 听唐渡梦发行包

本仓库只用于发布听唐渡梦的完整客户端、完整服务端和原生更新资产。公开仓库不包含私有源码、玩家数据、账号密码、部署密钥或原始运行日志。

## 版本与显示设置

当前候选版本为 v136.118.64。客户端默认使用 1024 × 768，可通过随包原生设置程序选择：

- 800 × 600
- 1024 × 768
- 1366 × 800

## 发布资产

每个版本的 GitHub Release 提供完整客户端 ZIP、完整服务端 ZIP、原生更新 .dt、客户端/服务端/feed 全量 SHA-256 清单和公开 SHA256SUMS。下载后请先核对 SHA-256。

服务端包使用零玩家初始种子；部署密钥保留为占位符，由部署负责人在目标环境中填写。

## 验收边界

Draft 版本仍待最终本地验收摘要和部署交接，不表示公网服务已经上线、端口已经可达或游戏业务已经验收。正式可下载版本以已发布的 GitHub Release 为准。
